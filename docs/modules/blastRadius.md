# Modul Blast-Radius Impact Analyzer

## Deskripsi Ringkas
Modul penganalisis area dampak perubahan berkas untuk mendeteksi potensi *breaking changes* dan memandu perencanaan migrasi bertahap (*staged migration planner*).

## Komponen
- `primitives/BlastRadiusModal.tsx`: Tampilan modal penganalisis radius dampak.
- `primitives/StagedMigrationPlanner.tsx`: Perencana tahap migrasi berkas yang terdampak.
- `logic/useBlastRadius.ts`: Hook pengelola analisis dampak berkas.
