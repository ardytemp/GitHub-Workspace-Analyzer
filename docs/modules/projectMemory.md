# Modul Hierarchical Project Memory & ADR

## Deskripsi Ringkas
Sistem indeks memori hierarkis dan *Hybrid Search* untuk aturan keputusan arsitektur (ADR), dokumen panduan, dan pencatatan *Scratchpad Agent*.

## Komponen
- `primitives/ProjectMemoryModal.tsx`: Modal penjelajah ADR dan memori hierarkis.
- `primitives/HybridSearchView.tsx`: Tampilan pencarian berbasis hybrid semantik dan keyword.
- `primitives/AgentScratchpadView.tsx`: Catatan kerja Agent dan epics.
